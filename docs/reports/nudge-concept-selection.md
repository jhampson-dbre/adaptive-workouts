## Round 2 accessible descriptions

### Concept A — Nerdy Training Partner

A bright, compact statistical workbench with large sans-serif headings, monospaced
figures and annotations, thin connector lines, blue actions, and restrained gray panels.
Desktop Plan places the real inputs beside a conspicuous explanation and calculation
column. Review pairs compact comparison tables. Mobile Performance and History use dense,
precisely aligned operational rows. The generated Plan also invents unsupported reasons,
training-history claims, a three-block preview, assistance work, and a buffer calculation;
these are visual examples only and cannot enter the product contract.

### Concept B — Cool Athlete Coach

A high-contrast black-and-white performance system with an architectural dark side rail,
oversized page typography, broad horizontal action zones, generous negative space, and
sport-specific line icons. Mobile Performance shifts into a dark timing header above a
bright active-set surface, producing the strongest prepare-to-train mode change. Review
turns actual-versus-planned values into progress rails. Mobile History is extremely
compact and approaches illegibility at the supplied viewport.

### Concept C — Technique Master

A monochrome, tightly registered technical system using squared rules, exact columns,
heavy black actions, tabular records, and almost no decoration. Plan and Review resemble
carefully composed forms or inspection sheets. Mobile Performance isolates the active set
and keeps both rest states visible. History uses strict stacked records. The result is
disciplined and truthful, but visually close to a refined conventional application and
can feel institutional rather than masterful.

## Round 2 provisional recommendation

Round two initially favored the **Concept A family** because it best expressed that Nudge
remembers and reasons while the user's choices remain central. The generated A was not
accepted as the final visual direction: it pushed the statistical intelligence into an
analytical workbench aesthetic and fabricated a recent-load claim, `>72h` history claim,
block preview, assistance work, and buffer calculation.

The user clarified that the “nerdy” intelligence is the product engine, not the interface
expression. Concept A therefore requires a warmer, more approachable visual replacement
using only truthful supplied content before final selection.

Use B as a reference for the active-workout mode shift, decisive action scale, and
athletic confidence—not as a second concept to merge wholesale. C is useful as a
discipline check for alignment and restraint, but it is not distinctive enough to lead.

### Final recommendation

Select **A-r3 — Warm Training Partner**.

It now communicates Nudge's relationship without turning the underlying intelligence
into a visual gimmick or inventing product behavior. It is the best balance of Journal,
Instrument, and Training Partner. Selection should preserve its warmth, human-scale
hierarchy, truthful contextual explanations, and prepare/reflect calm.

Treat the orange intensity, literal Warmup/Performance/Cooldown illustrations, oversized
desktop whitespace, and undersized mobile History text as concept-rendering artifacts,
not implementation requirements. B remains a useful comparison for active-workout
energy; C remains a useful discipline check, but neither should be merged wholesale into
the selected system.

## Round 1 accessible descriptions

### Concept A — Measured Ledger

A four-frame contact sheet on a warm off-white field. Heavy ruled lines, aligned columns,
large upright headings, a serif Nudge wordmark, and rust-orange actions create an
editorial ledger character. Desktop Plan and Review use numbered left margins to divide
the page into stages. Mobile Performance compresses the current exercise, two concurrent
rest readouts, and actions into horizontal instrument-like rows. Mobile History presents
phase, set, recommendation, and timing data in a dense but orderly record.

### Concept B — Calibrated Console

A four-frame contact sheet using white and mineral gray with deep teal actions and amber
warnings. Desktop Plan uses a split layout and a visibly calibrated time slider.
Performance groups the active set into a bordered operational panel with compact
collapsed exercise rows. Review uses side-by-side phase and exercise tables with explicit
deltas and status icons. History uses compact bordered records. A blue focus ring is
visible on the Plan action.

### Concept C — Attentive Relay

A four-frame contact sheet on a soft bone field with charcoal type, teal actions, rounded
borders, and generous spacing. Plan, Performance, and Review add a three-step
Prepared–Now–Next sequence rail. Plan emphasizes the prepared-workout message; Review
uses large actual-versus-planned values and plain-language confirmation states. The
mobile frames use broad actions and vertically stacked records with a softer,
partner-oriented tone.

## Superseded round 1 recommendation

Select **Concept A — Measured Ledger** as the source direction.

It is the only concept that feels simultaneously product-specific, calm, precise, and
capable of carrying dense workout history without becoming either a generic dashboard
or a fictional workflow. Its weaknesses are refinements rather than structural
problems:

- Remove the `01 / 02 / 03` rail as a universal pattern; it implies steps where the
  product has sections.
- Preserve the current native range input rather than replacing it with a number-only
  control.
- Strengthen the active-workout mode shift using contrast and scale, not more chrome.
- Verify the rust action color against contrast requirements and retain visible focus
  treatment as explicit as Concept B's.

Concept B is the best reference for control fidelity, focus visibility, and operational
density, but not for Nudge's identity. Concept C contains useful warmth and human-scale
spacing, but its Prepared–Now–Next rail and duplicate Plan action would require inventing
or implying behavior that EPIC-13 explicitly excludes.
