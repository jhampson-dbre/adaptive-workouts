# Prompt A, refinement — Warm Training Partner

Create a polished product-design contact sheet for **Nudge**, using the complete shared
brief below.

Concept A is the **Warm Training Partner**: attentive, prepared, and genuinely pleasant
to spend a workout with. The product's statistical intelligence is the invisible engine,
not the visual theme. Do not express intelligence through monospace styling, calculation
rails, analytical annotations, dense dashboards, debug-console cues, or technical
decoration. The interface should feel like a capable training partner has quietly
prepared the room before the user arrives.

Express warmth and approachability through the interface itself:

- Use a soft warm canvas, deep charcoal text, and one confident, accessible accent family.
- Use friendly, open typography with a natural reading rhythm and clear tabular numerals
  only where values need to align.
- Use comfortable spacing, softened geometry, and generous breathing room around the
  user's choice and next action.
- Keep existing explanatory copy close to the value it explains, as a calm helpful aside
  rather than an analysis panel.
- Build a relationship-led composition: preparation first, user choice clearly available,
  action easy to reach, and remembered context presented with care.
- Let the interface feel conversational through hierarchy and proximity without adding
  speech bubbles, jokes, mascots, or simulated dialogue.

The personality must come from composition, typography, rhythm, and the treatment of
real information—not from invented copy. On the Plan screen, no recommendation reason
or workout preview is supplied. Show only the time budget, selected muscle groups, and
actions listed below. Do not invent a `Why this plan fits` panel, recent-load claim,
session-age claim, exercise list, workout block, assistance work, duration calculation,
buffer, or any other plan detail. Across all four frames, render only the labels, values,
states, and explanatory sentences explicitly supplied below.

Give the four screens a coherent but responsive grammar. Desktop Plan should feel open,
welcoming, and choice-led. Mobile Performance should become more energetic while keeping
the ready set, both concurrent rests, and the existing recommendation sentence instantly
scannable. Desktop Review should feel calm, honest, and reassuring while making the
actual-versus-planned comparisons easy to inspect. Mobile History should feel like useful
remembered context, not a compressed database table.

Avoid rainbow-coded exercises, cute illustrations, generic card stacks, handwriting,
notebook cosplay, avatars, chat UI, charts, calculation panels, developer-tool styling,
monospace-led visual identity, and cold monochrome minimalism. Warmth must not reduce
information density, contrast, focus visibility, or mobile target size.
