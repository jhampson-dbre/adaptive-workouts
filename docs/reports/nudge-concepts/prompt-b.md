# Prompt B — Calibrated Console

Create a polished product-design contact sheet for **Nudge**, using the complete shared
brief below.

Concept B is **Calibrated Console**: the instrument leads, with memory and partner warmth
carried through evidence and measured language. Use a compact grid, crisp boundaries,
high-information bands, tabular numerals, and calibration ticks only where they map to
real ranges, timers, targets, or actual-versus-planned comparisons. Favor a light
mineral-gray field, near-black ink, off-white working surfaces, and a restrained
verdigris or amber signal color. Desktop may use purposeful split panes; mobile should
compress into a single operational column with a stable next-action zone. The active
frame should feel focused and energetic through contrast and scale, while Plan, Review,
and History remain calm. Dense data should scan like a dependable tool, not a dashboard
of tiles.

Do not mimic a medical monitor, aircraft cockpit, sci-fi HUD, or industrial control
panel. No decorative gauges: every mark must correspond to content in the brief.
