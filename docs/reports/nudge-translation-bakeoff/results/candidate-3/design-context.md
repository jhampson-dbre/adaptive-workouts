# A-r3 Warm Training Partner — design context

The interface is a prepared training room: warm paper-like canvas, charcoal reading text, and a single rust action color. It uses open ruled planes rather than dashboard cards so the workout feels cared for without adding invented reasoning.

- Plan makes the available time and user-controlled recovery choices the center of the room.
- Performance tightens into a focused, outlined ready-set instrument; both rest states stay independently visible below it.
- Review and History return to calm records, with tabular timing and plain-language annotations placed beside the values they qualify.

The implementation uses system and fallback fonts so the prototype remains stable without a font dependency.
