### 4. [P2] Large seeded plans remain long on phones

The first next action and alternate exercises remain ordered correctly, but an eight-exercise plan necessarily scrolls. No new navigation or virtualization is justified without usage evidence.

### 5. [P2] Some supporting labels are visually small

Core headings, controls, native focus behavior, and touch targets are strong. A broader typography adjustment would affect the approved visual system and is not required by the observed task flows.

## Cognitive Load

The primary decision is consistently isolated. Optional recovery and remaining-work content use native disclosures. Long generated plans are the only repeated high-option surface, with the focused set ordered before alternatives.

## Emotional Journey

Plan is decisive, Performance is the peak of clarity, Cooldown makes stopping legitimate, and Review ends factually. The persistent saved state improves the peak-end effect and confidence in persistence.

## Persona Red Flags

- A first-timer cannot revise a generated plan before starting without returning through existing navigation.
- A keyboard or screen-reader user benefits from native controls and focus movement, though long plans still create a long linear sequence.
- A distracted mobile user receives clear next actions, guardrails, and an explicit saved ending.
- An irregular-schedule trainee is not shown guilt-oriented elapsed-day copy in the inline leg-day choice.
