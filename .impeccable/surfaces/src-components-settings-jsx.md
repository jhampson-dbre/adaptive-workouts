# Nudge settings and catalog

Required mobile-first Operate extension for infrequent defaults and catalog maintenance. Preserve all current persistence, validation, alerts, mutations, and Close/Cancel semantics.

Hierarchy is Settings and Close, General defaults, Add exercise, then Current catalog. Add is the sole yellow action unless a row is being edited; then Save is yellow and Add is neutral. Every row visibly states Active or Inactive and reports Default rest or Override: N seconds. Blank rest fields use the default. Phone order remains single-column; wider screens may widen the defaults group without reordering it.
