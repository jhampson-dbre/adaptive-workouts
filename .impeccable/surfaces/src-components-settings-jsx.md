# Nudge settings and catalog

Required mobile-first Operate extension for infrequent defaults and catalog maintenance. Preserve all current persistence, validation, alerts, mutations, and Close/Cancel semantics.

Hierarchy is Settings and Close, a four-link job index, then native mounted details in Catalog, Defaults, Supersets, and Saved exercise orders order. Catalog alone starts open. Catalog filters are local, case-insensitive, and derived from a copied alphabetical view; inactive items remain hidden until requested. Add exercise is a closed native disclosure with mode-first fields and optional Advanced controls. Defaults preserves its existing save boundaries while grouping Recovery, Workout timing, and Schedule. Supersets use local Choose, Arrange, Review presentation steps over the existing draft and save path. Saved orders wraps the App-owned panel and keeps Clear available unconditionally. Phone order remains single-column; wider screens only widen working controls.
